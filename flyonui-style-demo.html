什么是 FlyonUI？
FlyonUI 是一个基于 Tailwind CSS 的开源组件库，语义化类名并内置交互式 JS 插件（手风琴、下拉菜单、弹窗等）。
这个 Demo 用了什么技术？
页面使用 Tailwind CSS 浏览器版 CDN + daisyUI CDN 实现，语义类名（btn / card / modal 等）与 FlyonUI 高度一致，无需构建，双击即可预览。
如何切换主题？
点击右上角的太阳图标，选择不同主题即可实时切换整个页面的配色方案。
