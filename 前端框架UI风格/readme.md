
五个单文件 HTML 做好了，下载后双击就能在浏览器里打开。它们不依赖 CDN 和任何外部资源，断网也能看。

| 文件 | 风格 | 特点 |
|---|---|---|
| `1-element-ui.html` | Element UI | 深蓝侧边栏的后台布局，蓝色主色，顶部居中的 Message 提示 |
| `2-mui-material.html` | Material UI | AppBar、悬浮按钮、按钮点击的水波纹、浮动标签输入框、左下角 Snackbar（删除后可撤销） |
| `3-ant-design.html` | Ant Design | 统计卡片、圆角表格和彩色 Tag、顶部下滑的 message |
| `4-bootstrap.html` | Bootstrap 5 | 深色导航栏、Hero 区、可关闭的 Alert、进度条、斑马纹表格和 Modal |
| `5-shadcn-ui.html` | shadcn/ui | 黑白灰加细边框，带明暗主题切换（右上角按钮，默认跟随系统），Tabs、Dialog 和右下角 Toast |

每个文件里的按钮、输入框、开关、标签、表格、弹窗和消息提示都能点，订单表格支持搜索、新增和删除。

这些是用原生 CSS 对各框架视觉风格的还原，不是真实组件库。细节（字体、间距、动效）接近但不完全一致。
